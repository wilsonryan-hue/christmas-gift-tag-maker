# Free Christmas gift tag maker (one HTML file, nothing stored)

Type or paste a list of names and print a sheet of Christmas gift tags: "Merry Christmas, To Nan, Love from Charlie". Pick 8, 12 or 21 tags per A4 page, choose a style, and print. No sign-up, no server, no cookies, no build step: it is one `index.html` file.

**Use it now, no install:** download `index.html` and open it in any browser, or see the ready-made printable sets at [tchworks.co.uk/free/christmas-gift-tags-printable-2026](https://www.tchworks.co.uk/free/christmas-gift-tags-printable-2026/?utm_source=github&utm_medium=repo&utm_campaign=gift-tag-repo).

## What it does

- Makes one tag per name, up to 300 names, with 1 to 4 copies of each.
- Three sizes on A4: 8 large tags (99 x 74 mm), 12 medium tags (105 x 49.5 mm) or 21 small tags (70 x 42.4 mm).
- A top line to choose from (Merry Christmas, Happy Christmas, With love, Season's greetings, Ho ho ho, or none) and an optional "From" line printed on every tag.
- Four styles: red, green, midnight blue and plain black, which saves ink.
- Optional hole-punch circle and optional dashed cut lines.
- Leave the names box empty to print blank tags with "To" and "From" lines to write on by hand.
- Typed text is shown as text only, never run as code.

## Use it

Open `index.html`, paste your names (one per line), press **Make my tags**, then **Print**. Print at 100 percent (actual size) on A4 with margins set to none, ideally on thin card. Cut along the dashed lines, punch the hole and thread some string or ribbon through it.

Tested in headless Chrome: 10 names at 8 per page print 2 A4 pages, 23 names at 12 per page print 2 pages, and 23 names at 21 per page print 2 pages. A 38-character name wraps onto two or three lines and stays inside its tag.

## Self-host

Put `index.html` on any static host (GitHub Pages, Netlify, a school intranet). There is nothing to configure.
